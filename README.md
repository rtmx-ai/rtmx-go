# This repository has been merged into [rtmx-ai/rtmx](https://github.com/rtmx-ai/rtmx)

**All future development happens at [github.com/rtmx-ai/rtmx](https://github.com/rtmx-ai/rtmx).**

This repository (`rtmx-go`) was the Go implementation of the RTMX CLI. As of v0.2.0, it has been merged into the main `rtmx` repository, replacing the Python CLI as the primary implementation.

## Install

```bash
brew install rtmx-ai/tap/rtmx
```

Or see [github.com/rtmx-ai/rtmx](https://github.com/rtmx-ai/rtmx) for all installation methods.

## For Go module users

The Go module path has changed:

```
# Old (no longer updated)
go install github.com/rtmx-ai/rtmx-go/cmd/rtmx@latest

# New
go install github.com/rtmx-ai/rtmx/cmd/rtmx@latest
```

This repository is archived and read-only. The full commit history is preserved in the [rtmx-ai/rtmx](https://github.com/rtmx-ai/rtmx) repository.
